# dsh-locale-ru — русская локализация DeepSeek Harness

Языковой пакет для клиента DeepSeek Harness: добавляет локаль `ru-x-dsh`
(«Русский (улучшенный)») с вычитанным русским словарём на **3879 строк в 73
namespace** — весь пользовательский интерфейс: чат, вложения, вызовы
инструментов, настройки, модели, менеджер и каталог плагинов, боковые панели,
терминал, предпросмотр документов, траектория, статистика, Live Share, Forge.

Ничего в приложении не патчится: пакет использует публичный API локали
(`ctx.locale.addLanguage` / `ctx.locale.register`) и живёт как плагин профиля.

## Почему отдельная локаль

Штатный русский словарь DSH — машинный перевод: «сеанс» и «сессия» в одном
экране, «рабочее пространство» и «рабочая область», «предустановка» и «пресет»,
кальки и битые конструкции («переключиться на модель, которая делает»),
«ты»-формы вперемешку с «вы». Словарь лежит внутри подписанного `app.asar`,
поэтому правится только пересборкой приложения. Пакет добавляет новую локаль
поверх штатной.

## Установка

Пакет — это каталог [`pkg/`](pkg). Установка в профиль:

```
plugin_manager  action: install_bundle  target: <путь к этому репозиторию>/pkg
```

или из чекаута:

```bash
dsh plugin add /путь/к/dsh-locale-ru/pkg
```

Затем включите язык: **Настройки → Основные → Язык → «Русский (улучшенный)»**.
При первом запуске пакет сам один раз переключает на себя тех, у кого выбран
штатный русский (отметка в `localStorage`, чтобы не спорить с осознанным
выбором).

Откат: выбрать в том же списке «Русский» или English; удалить —
`plugin_manager → remove_bundle` для `@local/dsh-locale-ru`.

## Как это работает

```js
ctx.locale.addLanguage({ id: 'ru-x-dsh', label: 'Русский (улучшенный)', fallback: 'ru' })
ctx.locale.register(ns, 'ru-x-dsh', dict)   // по одному вызову на namespace
```

Цепочка фолбэков — `ru-x-dsh → ru → en`. Всё, чего нет в пакете, показывается из
штатного русского, а дальше из английского: обновление DSH не ломает перевод, а
новые строки просто появляются на штатном русском до следующей вычитки.

## Сторонние плагины

В профиль ставятся плагины не от DeepSeek, и часть их интерфейса написана на
китайском с английским. Пакет переводит те, что регистрируют словари в общий
реестр локали (`ctx.locale.register`), — сейчас это `dsh-tidy-display`
(«Просмотр» диалога) и `dsh-vision-router` (маршрутизация изображений):

| Плагин | Как получает русский |
| --- | --- |
| `dsh-tidy-display` | свой `ru` уже был; пакет вычитывает его поверх |
| `dsh-vision-router` | регистрирует только `zh`/`en`; русский даёт пакет |
| `dsh-better-sidebar` | свой `t()` мимо реестра — нужен `@huanlin/dsh-plugin-better-locale`, словарь `ru` в комплекте плагина |
| `dshmarket` | словари собираются в фабрике, ключи не извлечь статически — нужен апстрим |
| `dsh-claude-style`, `dsh-cost-meter` | собственный переключатель `zh`/`en` без `ctx.locale` — снаружи не переводится |

Строки плагинов лежат отдельно от основного корпуса: `tools/vendor/vendor-corpus.jsonl`
(вход) и `tools/out-vendor/*.jsonl` (перевод), сборка `tools/build.py` подхватывает оба.

## Принципы перевода

- **Один термин на понятие:** сессия, ход/шаг, рабочая область, пресет,
  инструмент, субагент, промпт, провайдер, установка, подтверждение, навык.
- **Один голос:** инфинитив для действий («Отправить»), «вы» без местоимения в
  подсказках («Выберите модель»), безличные ошибки («Не удалось сохранить»).
  «Ты»-форм нет.
- **Счётные формы, грамматичные при любом числе:** «Вызовов: {count}»,
  «Изображений: не больше {count}».
- ё, «ёлочки», длинное тире, sentence case, никаких «пожалуйста».
- Плейсхолдеры `{count}`, `/команды`, `@ссылки`, `snake_case` — побайтово.

Полные правила и глоссарий — [`tools/style-guide.md`](tools/style-guide.md).

## Структура

```
pkg/                     устанавливаемый плагин
  package.json           манифест: dsh.bundle.patch + dsh.client
  client.js              сгенерированный бандл: словари + регистрация локали
  index.js               хост-половина, намеренно пустая
  cordis.patch.yml       вставляет строку плагина в профиль
  locale/{en,ru}.json    название и описание плагина в инвентаре
  icon.svg               иконка
tools/                   конвейер вычитки
  extract.py             вытащить строки из исходников DSH
  group.py               разложить на группы
  out/group-NN.jsonl     вычитанный перевод ({"ns","key","ru"})
  overrides.jsonl        точечные правки поверх групп
  validate.py            плейсхолдеры, глоссарий, запреты
  build.py               собрать pkg/client.js
  patch_build.py         собрать патч для исходников DSH (см. docs/PATCH.md)
docs/
  PATCH.md               тот же текст как патч в чекаут DSH
  PR.md                  описание для PR в upstream
```

## Обновление после апдейта DSH

```bash
cd tools
python3 extract.py && python3 group.py   # новый корпус по новым исходникам
# вычитка out/group-NN.jsonl
python3 validate.py && python3 build.py  # пересобрать pkg/client.js
```

После замены `pkg/client.js` требуется перезагрузка страницы (новое поколение
клиентского модуля подхватывается при перезапуске приложения).

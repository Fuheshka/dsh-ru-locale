# @local/dsh-locale-ru — русский язык для DeepSeek Harness

Языковой пакет для клиента DSH: регистрирует локаль `ru-x-dsh` с подписью
**«Русский (улучшенный)»** и словарями на 3879 строк в 73 namespace. Цепочка
фолбэков — `ru-x-dsh` → `ru` → `en`, поэтому строки, которых нет в пакете,
показываются из штатного русского словаря, а не пропадают.

## Зачем отдельная локаль

Штатный русский словарь лежит внутри подписанного `app.asar` и правится только
пересборкой приложения. Пакет добавляет новую локаль поверх него через публичный
API `ctx.locale.addLanguage` / `ctx.locale.register` и ничего в приложении не
меняет.

## Как включить и выключить

- Включить: **Настройки → Основные → Язык → «Русский (улучшенный)»**. При первом
  запуске пакет сам переключает читателя, у которого выбрана штатная русская
  локаль (однократно, отметка в `localStorage`).
- Выключить: там же выбрать «Русский» (штатный) или English.
- Удалить: `plugin_manager` → `remove_bundle` для `@local/dsh-locale-ru`.

## Состав

| Файл | Назначение |
| --- | --- |
| `client.js` | сгенерированный клиентский бандл: словари + регистрация локали |
| `index.js` | хост-половина, намеренно пустая |
| `cordis.patch.yml` | вставляет строку `ru-locale-pack` в профиль |
| `locale/{en,ru}.json` | заголовок и описание плагина в инвентаре |
| `icon.svg` | иконка плагина |

## Сторонние плагины

Пакет переводит и те плагины профиля, что регистрируют словари через
`ctx.locale.register`: `dsh-tidy-display` и `dsh-vision-router`. Плагины со своим
переключателем языка (`dsh-claude-style`, `dsh-cost-meter`) или со словарями,
собранными в фабрике (`dshmarket`), снаружи не переводятся; `dsh-better-sidebar`
требует `@huanlin/dsh-plugin-better-locale`.

## Как править перевод

`client.js` не редактируется руками: он собирается из корпуса.

```bash
cd "../.dsh-locale-ru/tools"
python3 extract.py     # вытащить строки из исходников DSH 0.2.2-rc.1
python3 group.py       # разложить на группы по ~250 строк
# перевод/вычитка: out/group-NN.jsonl  ({"ns","key","ru"})
python3 validate.py    # плейсхолдеры, глоссарий, запреты
python3 build.py       # собрать ../pkg/client.js
```

`tools/style-guide.md` — правила и глоссарий (единый стиль, термины, обращение,
счётные формы). `tools/overrides.jsonl` — точечные правки поверх групп.

После обновления DSH стоит заново прогнать `extract.py` + `group.py`: новые ключи
появятся в корпусе, а старые продолжат работать через фолбэк.

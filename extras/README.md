# extras — фиксы, которые не входят в языковой пакет

Здесь лежат исправления и патчи, которые мы делали отдельно от словарей
`pkg/`. Языковой пакет остаётся обычным плагином локали; эти файлы
устанавливаются поверх сторонних плагинов и не меняют `pkg/client.js`.

| Каталог | Что исправляет | Установка |
| --- | --- | --- |
| [cost-meter-rub](cost-meter-rub/) | цены API в `₽ / $` вместо юаней + автопереприменение после обновления | `./cost-meter-rub/install-autofix.sh` |
| [claude-style-perf](claude-style-perf/) | лишние записи в DOM в теме Claude Style 0.20.3 | `dsh plugin add ./claude-style-perf/dsh-claude-style-0.20.3.tgz` |
| [panel-balance](panel-balance/) | карточка расходов в футере вместо поповера аккаунта; баланс из официального аккаунта | настройки DSH, см. README |

## Важно

- Это не часть устанавливаемого пакета `pkg/`: `dsh plugin add` для
  локализации не тянет `extras/`.
- Патчи живут в `node_modules` установленных плагинов и слетают при их
  обновлении. Для `dsh-cost-meter` есть launchd-автофиксер; для темы
  нужно переустановить собранный `tgz` после обновления.
- Секреты, `ledger.json`, `.credentials.yaml` и резервные копии сюда не
  коммитятся. В `panel-balance` описано, какие настройки выставлены, без
  самих ключей.
- Проверено на DSH Desktop, `dsh-cost-meter@1.9.64`,
  `dsh-claude-style@0.20.3`, macOS. После крупного обновления плагинов
  якоря патчей могут измениться.
